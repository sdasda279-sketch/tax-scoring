# Telegram bot

1. Telegram'da @BotFather ga `/newbot` yozing, token oling.
2. Muhit o'zgaruvchilari:
   - Windows (cmd):  `set TELEGRAM_BOT_TOKEN=SIZNING_TOKEN`  va (ixtiyoriy) `set ADMIN_IDS=SIZNING_ID`
   - Linux/Mac:      `export TELEGRAM_BOT_TOKEN=...`
3. `python bot.py`  (qo'shimcha kutubxona kerak emas; birinchi marta ma'lumotlar o'zi yaratiladi)
4. Botga `/id` yozib Telegram ID ingizni bilib oling va ADMIN_IDS ga qo'ying (admin buyruqlari: /top10, /statistika, /yubor).
